# Target search terms

The searches worth holding a page for. Edit this list — `scripts/coverage.mjs`
reads it and reports which terms have a page and which do not.

A term earns its place here when a bride would plausibly type it *and* the
studio can genuinely serve what it promises. A page for something the studio
does not do costs more than the traffic is worth.

## Style

- שמלות כלה בוהו
- שמלות כלה בוהו שיק
- שמלות כלה עם שרוולים
- שמלות כלה עם גב פתוח
- שמלות כלה עם שובל
- שמלות כלה תחרה
- שמלות כלה רומנטיות

## Place

- סטודיו שמלות כלה בהוד השרון
- שמלות כלה בשרון

## Fit and segment

- שמלות כלה למלאות
- שמלות כלה בהתאמה אישית
- שמלות כלה תפורות לפי מידה

## Deliberately not targeted

Listed so a later run does not rediscover them as an oversight.

**Price.** The owner has decided against publishing price information, so the
price terms the competitors hold — מחיר שמלת כלה, שמלות כלה זולות — are out
of scope.

**International shipping.** No competitor holds it and the studio genuinely
ships abroad, which made it the strongest open term in the set. The owner
decided against a page for it (September 2026). It stays here as the one term
to revisit if that changes.

- משלוח שמלת כלה לחול
- שמלת כלה מישראל לחול
